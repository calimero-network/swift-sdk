## Calls and views

```swift
let answer = try await client.call(app, "send_message", ["message": "hi"])   // POST /apps/{app}/intents
answer.index; answer.result; answer.events
let read = try await client.view(app, "get_messages", [:])                   // POST /apps/{app}/views
```

- A call carries an idempotency key (`node:c-…` unless you pass one). While
  the node answers `503` or cannot be reached, the same request with the same
  key is sent again: 6 retries, 200 ms doubling to 2 s, or the node's
  `Retry-After` when longer (`CloudRetryOptions`). Then `UnavailableError`,
  whose `committed` is `.no` or `.unknown`.
- An app's own refusal is `AppError` with `appCode` and `fields`.
- `callJSON` / `viewJSON` take and return JSON bytes, every number as written
  (a `u64` beyond 2^53); `CloudContextContract` uses them.

## Events

```swift
for try await event in client.events(app, from: 0) { … }   // GET /apps/{app}/events, sealed SSE
```

Each event has `id` (`index:seq`), `kind` and `data`. Cancel the task (or stop
iterating) to close the stream.

## Orgs, teams, invites

| Call | Route |
| --- | --- |
| `createOrg(name)`, `getOrg(org)`, `setOrgMetadata` | `/orgs`, `/orgs/{org}` |
| `createTeam(org, name:, join: .everyone/.invite)`, `getTeam`, `updateTeam`, `deleteTeam` | `/orgs/{org}/teams/…` |
| `setMember`, `removeMember`, `setTeamMember`, `setCapabilities` | `/orgs/{org}/members`, `…/capabilities` |
| `invite(org, role:, teams:)` → `inv_…` | `POST /orgs/{org}/invites` |
| `redeemInvite(token)` | `POST /invites/{token}/redeem` |
| `createApp(name, bundle: .package(…), org:, access: .team(id))` | `POST /apps` |

`me()` lists the account's organizations.

## Blobs and presence

`uploadBlob(app, data)`, `downloadBlob(app, id)`, `listBlobs`, `blobInfo`,
`deleteBlob` on `/apps/{app}/blobs`; `publishPresence`, `presence`,
`presenceStream` on `/apps/{app}/presence`.
