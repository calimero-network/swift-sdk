## The device is a thin client

MeroKit never runs a node. A Calimero 1.0 cluster is a set of attested TDX
nodes; each app instance is one replicated log on them. MeroKit is the Swift
port of [mero-js](https://github.com/calimero-network/mero-js)'s
`CalimeroClient`: the same methods, the same errors, the same retry and
failover rules.

| Layer | What it is |
| --- | --- |
| `MeroKitUI.MeroAppSession` | An app's signed-in account and its `MeroAppBackend` (orgs, teams, app instances, invites, events). |
| `MeroKitUI.MeroClient` | The observable session: sign-in, restore, sign-out, the consent page. |
| `MeroKit.CalimeroClient` | Every node route, typed errors, refresh and failover. |
| `MeroKit.SealedTransport` | Noise NK to the attested transport key (`calimero/sealed-http/v2`), sealed frames. |
| `MeroKit` TEE trust | Mock or real quotes: signed mero-tee releases (Sigstore), DCAP against Intel's collateral. |
