MeroKit streams a node's real-time context events over Server-Sent Events. The
task-oriented walkthrough is the [live events guide](/guides/events/); this page
is the API surface.

## `mero.events(contextIds:groupIds:)`

```swift
nonisolated func events(
    contextIds: [String], groupIds: [String] = []
) -> AsyncThrowingStream<ContextEvent, Error>
```

Opens `GET /sse` (bearer token in the `Authorization` header) and subscribes to
the given context and group ids via
`POST /sse/subscription`, then yields a `ContextEvent` per emission. It is
`nonisolated` — callable without `await` — and reconnects automatically after a
drop with `ReconnectBackoff.sse` (below), re-subscribing its ids on the new
session. Consume it with
`for try await`; **cancel the enclosing `Task` to close the connection**.

```swift
let task = Task {
    for try await event in mero.events(contextIds: [contextId]) {
        print(event.contextId, event.kind)
        await reload()
    }
}
// later:
task.cancel()   // closes the SSE stream
```

<Aside type="note">
  `mero.close()` (and `mero.logout()`) ends every stream the instance started;
  the `for try await` loop finishes normally. Cancelling the `Task` closes one
  stream.
</Aside>

## `mero.groupEvents(groupIds:)` / `mero.nodeEvents(contextIds:groupIds:)`

Typed streams, like the Kotlin SDK's `groupEvents` / `nodeEvents`:

```swift
nonisolated func groupEvents(groupIds: [String]) -> AsyncThrowingStream<GroupEvent, Error>
nonisolated func nodeEvents(
    contextIds: [String], groupIds: [String]
) -> AsyncThrowingStream<NodeEvent, Error>

public struct GroupEvent: Sendable, Equatable {
    public let groupId: String     // hex
    public let kind: String        // "MemberAdded", "MemberRemoved", "MigrationCompleted", ...
    public let payload: JSONValue  // the raw `result` JSON
}

public enum NodeEvent: Sendable {
    case context(ContextEvent)
    case group(GroupEvent)
    public var contextEvent: ContextEvent { get }  // the untyped form `events` yields
}
```

```swift
for try await event in mero.nodeEvents(contextIds: [chat], groupIds: [team]) {
    switch event {
    case .context(let e): await reloadMessages(e.contextId)
    case .group(let g) where g.kind == "MemberAdded": await reloadMembers(g.groupId)
    case .group: break
    }
}
```

`groupEvents` subscribes no contexts and yields only group events.

## `ContextEvent`

```swift
public struct ContextEvent: Sendable {
    public let contextId: String   // "" for a group-keyed event
    public let kind: String        // "StateMutation", "SyncStatus", "Ephemeral", "MemberJoined", ...
    public let payload: JSONValue  // raw event JSON
    public let groupId: String?    // set for a group-keyed event (core rc.83)

    public var presenceAccount: String? { get }  // Ephemeral: the relayed account (rc.83)
    public var presenceAuthor: String? { get }   // Ephemeral: the author's signing key
}
```

**Group events (core rc.83).** Pass `groupIds` to also receive group-keyed
events: membership (`MemberJoined`, `MemberAdded`, `MemberRemoved`, carrying
`memberAccount` and maybe `role`) and migration (`MigrationStarted`,
`MigrationProgress`, `CascadeProgress`, `MigrationCompleted`). They arrive with
`groupId` set. `groupIds` is sent only when non-empty, so a context-only
subscription is the same body an older node accepts. A client key can only
subscribe to the contexts and groups it is bound to.

**Presence.** An `Ephemeral` event's `data.account` names the account behind a
presence update a relay carried; `presenceAccount` reads it.

For a state change (`kind == "StateMutation"`) the encoded contract events
live under `payload`'s `data.events[].data`.

## `SseClient`

`mero.events(...)` builds an `SseClient` for you; use it directly only if you
need to manage the connection yourself.

```swift
public final class SseClient: @unchecked Sendable {
    public init(
        baseURL: URL,
        token: @escaping @Sendable () async -> String?,
        session: URLSession = .shared
    )
    public func events(
        contextIds: [String], groupIds: [String] = []
    ) -> AsyncThrowingStream<ContextEvent, Error>
    public func groupEvents(groupIds: [String]) -> AsyncThrowingStream<GroupEvent, Error>
    public func nodeEvents(
        contextIds: [String], groupIds: [String]
    ) -> AsyncThrowingStream<NodeEvent, Error>
}
```

Each stream an `SseClient` hands out runs on its own `SseConnection` and closes
it when the stream ends. A standalone `SseClient` is not tracked by any `Mero`,
so `mero.close()` does not end its streams. `SseClient` also has
`appVersionChanges(contextIds:)`, `migrationEvents(groupIds:)` and
`connection()` (a new, unconnected `SseConnection`); its `init` takes
`backoff:`.

## `SseConnection`

One long-lived connection (== mero-js `SseClient`). `mero.sse` is the
instance's shared one; `mero.close()` closes it.

```swift
public final class SseConnection: @unchecked Sendable {
    public static let subscriptionTimeout: TimeInterval   // 10 s
    public init(baseURL: URL, token: @escaping @Sendable () async -> String?,
                session: URLSession = .shared, backoff: ReconnectBackoff = .sse)

    public func connect()          // start; idempotent
    public func close()            // stop, forget subscriptions, end listeners' streams
    public var sessionId: String? { get }
    public var isRunning: Bool { get }

    public func subscribe(contextIds: [String] = [], groupIds: [String] = []) async throws
    public func unsubscribe(contextIds: [String] = [], groupIds: [String] = []) async throws
    public func isSubscribed(_ contextId: String) -> Bool
    public func isSubscribed(groupId: String) -> Bool
    public var subscribedContextIds: [String] { get }
    public var subscribedGroupIds: [String] { get }
    public func presenceSeed(_ contextId: String) -> [JSONValue]

    public func updates() -> AsyncThrowingStream<SseConnectionEvent, Error>
    public func events() -> AsyncThrowingStream<NodeEvent, Error>
    public func appVersionChanges() -> AsyncThrowingStream<AppVersionChangedEvent, Error>
    public func migrationEvents() -> AsyncThrowingStream<GroupMigrationEvent, Error>
    public func membershipEvents() -> AsyncThrowingStream<GroupMembershipEvent, Error>
    public func on(_ handler: @escaping @Sendable (SseConnectionEvent) -> Void) -> @Sendable () -> Void
    public func onAppVersionChanged(_ handler: …) -> @Sendable () -> Void
    public func onMigrationEvent(_ handler: …) -> @Sendable () -> Void
}

public enum SseConnectionEvent: Sendable {
    case connect(sessionId: String)   // after the remembered ids were re-subscribed
    case event(NodeEvent)
    case error(Error)                 // recoverable: the connection reconnects
}
```

- `subscribe`/`unsubscribe` change the remembered set and POST only the ids
  that changed to the live session (`{"id": session, "method":
  "subscribe"|"unsubscribe", "params": {contextIds, groupIds?}}`). Before a
  session exists the ids are sent with the next connect. A POST that fails or
  outlasts 10 s throws; the ids stay remembered.
- On every `connect` frame the whole remembered set is re-subscribed, then
  `.connect` is announced; a refused re-subscribe announces `.connect` and then
  `.error`. A `403` on the stream or the re-subscribe, or a `401` naming
  `token_revoked`/`token_reuse`, is terminal: every listener's stream throws
  that `MeroError`, nothing reconnects, and the subscriptions stay for a later
  `connect()`.
- Listening does not connect — call `connect()`.

## `ReconnectBackoff`

```swift
public struct ReconnectBackoff: Sendable, Equatable {
    public var initialDelay, multiplier, maxDelay, jitter
    public static let sse        // 3 s, ×2, ≤ 30 s, ±20%
    public static let webSocket  // 1 s, ×2, ≤ 30 s, no jitter (mero-js WsClient)
    public static func fixed(_ delay: TimeInterval) -> ReconnectBackoff  // mero-js SseClient
    public func delay(attempt: Int, random: Double = .random(in: 0..<1)) -> TimeInterval
}
```

The count resets whenever a connection opens. mero-js's SSE client waits a
flat `reconnectDelayMs` (3 s); `.sse` waits the same 3 s after a drop and
only grows while reconnects keep failing.

## Typed events

`ContextEvent.data` / `GroupEvent.data` decode the frame's `data` as mero-js
does (a byte array of UTF-8 JSON becomes that JSON). On top of it:

| Accessor | Type | From `type` |
| --- | --- | --- |
| `ContextEvent.appVersionChanged` | `AppVersionChangedEvent { contextId, fromVersion?, toVersion? }` | `AppVersionChanged` |
| `GroupEvent.membership` | `GroupMembershipEvent { groupId, kind, memberAccount, role? }` | `MemberJoined`, `MemberAdded`, `MemberRemoved` |
| `GroupEvent.migration` | `GroupMigrationEvent` | `MigrationStarted`, `MigrationProgress`, `CascadeProgress`, `MigrationCompleted` |

```swift
public enum GroupMigrationEvent: Sendable, Equatable {
    case migrationStarted(groupId: String, MigrationStartedData)
    //   fromVersion, toVersion, toStateVersion: UInt32, localContextsTotal: UInt32 (node-local)
    case migrationProgress(groupId: String, MigrationProgressData)
    //   migrated, inProgress, unknown, failed, total (the fleet cohort)
    case cascadeProgress(groupId: String, CascadeProgressData)
    //   subgroupId, localContextsSwapped, localContextsTotal — namespace admins only
    case migrationCompleted(groupId: String, MigrationCompletedData)
    //   toVersion, completedAt (seconds, fleet convergence)
}
```

Field names are core's (`calimero_primitives::events`). `role` is `Admin`,
`Member`, `ReadOnly`, `ReadOnlyTee` or `RelayTee`, absent on `MemberRemoved`.

## Presence

```swift
public struct EphemeralClient: Sendable {           // mero.ephemeral
    public let events: SseConnection

public struct EphemeralEntry<State> {
    public let author: String, account: String?, state: State?, removed: Bool, ageMs: UInt64?

public protocol Codec: Sendable { associatedtype Value; encode/decode as [UInt8] }
```

## `WsClient` (experimental)

`mero.ws` — port of mero-js's `@experimental` `WsClient`. Prefer `mero.sse`.

```swift
public final class WsClient: @unchecked Sendable {
    public init(baseURL: URL, token: @escaping @Sendable () async -> String?,
                connector: any WebSocketConnector = URLSessionWebSocketConnector(),
                backoff: ReconnectBackoff = .webSocket)
    public func connect()
    public func close()
    public var isOpen: Bool { get }
    public func subscribe(contextIds: [String] = [], groupIds: [String] = []) async
    public func unsubscribe(contextIds: [String] = [], groupIds: [String] = []) async
    public func updates() -> AsyncThrowingStream<WsClientEvent, Error>   // .connect, .event, .error
    public func events() -> AsyncThrowingStream<NodeEvent, Error>
}
```

It opens `GET /ws?token=…` (http→ws, https→wss; the token is
`encodeURIComponent`-encoded in the query, which is where core's `/ws` reads
it) and sends `{"id":null,"method":"subscribe","params":{"contextIds":[…],"groupIds":[…]}}`
(empty lists left out) for the ids passed, re-sending every remembered id
after each reconnect. Reconnects wait 1 s · 2ⁿ, capped at 30 s, reset when a
socket opens. `WebSocketTransport` / `WebSocketConnector` abstract the socket,
so a test can substitute one.

<Aside type="note">
  The stream uses a long-lived `URLSession.bytes(for:)` request. Don't back it
  with a background `URLSessionConfiguration` — streaming needs a standard
  (default/ephemeral) session. `SseClient` also imports `FoundationNetworking`,
  so it builds on Linux, but live streaming is intended for the Apple platforms
  MeroKit targets (iOS 15+ / macOS 12+).
</Aside>
