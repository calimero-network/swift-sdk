The entry point to the SDK — an `actor`, so every instance member is `await`ed
and token state is race-free.

```swift
import MeroKit

let mero = Mero(config: MeroConfig(
  baseURL: URL(string: "https://your-node.example")!,
  tokenStore: KeychainTokenStore()
))
```

## Initializers

```swift
public init(config: MeroConfig)                          // uses URLSession.shared
public init(config: MeroConfig, session: URLSession)     // inject a custom session (tests)
```

## Sub-client accessors

Computed properties that build a fresh value-type client over the shared
transport:

| Accessor | Type | Description |
| --- | --- | --- |
| `mero.auth` | `AuthApi` | login, tokens, key management — [reference](/reference/auth-api/) |
| `mero.admin` | `AdminApi` | contexts, apps, namespaces, groups, blobs, TEE — [reference](/reference/admin-api/) |
| `mero.rpc` | `RpcClient` | execute WASM methods — [reference](/reference/rpc/) |
| `mero.http` | `any HttpClient` | the transport in use (advanced) |
| `mero.ephemeral` | `EphemeralClient` | presence: `set_ephemeral` + subscribe — [guide](/guides/presence/) |
| `mero.sse` | `SseConnection` | the instance's one long-lived SSE connection (`nonisolated`) — [reference](/reference/events/#sseconnection) |
| `mero.ws` | `WsClient` | **experimental** WebSocket events (`nonisolated`) — [reference](/reference/events/#wsclient-experimental) |

Plus one method, not an accessor:

| Method | Returns | Description |
| --- | --- | --- |
| `mero.events(contextIds:)` | `AsyncThrowingStream<ContextEvent, Error>` | live SSE events — [reference](/reference/events/) |
| `mero.appVersionChanges(contextIds:)` | `AsyncThrowingStream<AppVersionChangedEvent, Error>` | typed `AppVersionChanged` events |
| `mero.migrationEvents(groupIds:)` | `AsyncThrowingStream<GroupMigrationEvent, Error>` | typed migration events |

## Authentication

```swift
@discardableResult
func authenticate(_ credentials: Credentials? = nil) async throws -> TokenData
```
Authenticate with credentials (falls back to `config.credentials`; throws
`MeroError.noCredentials` if neither is set). Builds a `user_password`
`TokenRequest` with client name `mero-swift-sdk` and permissions `["admin"]`,
calls `auth.generateTokens`, and persists the bundle.

## Token state

```swift
var isAuthenticated: Bool                     // await mero.isAuthenticated
func currentTokenData() -> TokenData?         // current bundle (debug / handoff)
func setTokenData(_ data: TokenData)          // set directly; derives expiresAt from the JWT
func setTokenData(from callback: AuthCallbackResult)  // from a parsed SSO callback
func clearToken()                             // drop the bundle + clear the store
func logout() async                           // POST /auth/logout (best-effort), clearToken() + close()
func close()                                  // end every event stream this instance started
```

**Tokens are bound to their node.** The copy `Mero` persists carries
`TokenData.nodeOrigin` — the node's origin plus path prefix
(`TokenData.nodeKey(for:)`, e.g. `https://host.example/node1`) — and a stored
bundle tagged for another node, or not tagged at all, is ignored: one Keychain
item shared by instances pointed at different nodes never sends node A's tokens
to node B (== mero-js `TokenData.node_origin`). `nodeOrigin` is optional, so a
bundle persisted by an earlier release still decodes, but it names no node and
is not restored: **sign in once after upgrading.**

<Aside type="note">
  All of the above are actor-isolated — call them with `await`
  (e.g. `let ok = await mero.isAuthenticated`).
</Aside>

<Aside type="note">
  `close()` (and so `logout()`) ends every live
  [`events` / `groupEvents` / `nodeEvents`](/reference/events/) stream this
  instance started, and closes the shared `sse` and `ws` clients (presence
  streams included): the connection is cancelled and the `for try await` loop
  ends normally. Streams opened afterwards work as usual. Cancelling the
  consuming `Task` still closes one stream on its own.
</Aside>

## SSO statics

Synchronous, non-throwing, and also available as free helpers on `SsoLogin`:

```swift
static func parseAuthCallback(
  _ url: String,
  options: ParseAuthCallbackOptions = ParseAuthCallbackOptions(),  // allowUnsolicited: false
  stateStore: AuthLoginStateStore = .shared
) -> AuthCallbackResult?
static func buildAuthLoginUrl(
  nodeUrl: String, options: AuthLoginOptions, stateStore: AuthLoginStateStore = .shared
) -> String
```

`buildAuthLoginUrl` begins a single-use login in `stateStore` and puts its
`auth_state` in the callback URL; `parseAuthCallback` returns `nil` for a
callback that does not carry a pending state (see
[authentication → hosted SSO](/get-started/authentication/#hosted-sso-deep-link)).

See [authentication → hosted SSO](/get-started/authentication/#hosted-sso-deep-link).

## Configuration types

### `MeroConfig`

```swift
public struct MeroConfig: Sendable {
  public var baseURL: URL
  public var credentials: Credentials?
  public var timeout: TimeInterval          // default 10
  public var tokenStore: (any TokenStore)?  // nil → in-memory
  public init(baseURL: URL, credentials: Credentials? = nil,
              timeout: TimeInterval = 10, tokenStore: (any TokenStore)? = nil)
}
```

### `Credentials`

```swift
public struct Credentials: Sendable, Equatable {
  public var username: String
  public var password: String
  // Two fields, deliberately. core 0.11.0-rc.17 moved admin provisioning to
  // `merod init`, so there is no first-login setup code to carry any more.
  public init(username: String, password: String)
}
```

### `TokenData`

```swift
public struct TokenData: Codable, Sendable, Equatable {
  public var accessToken: String
  public var refreshToken: String
  public var expiresAt: Date   // informational; the SDK never refreshes proactively
}
```

On the wire these are `access_token`, `refresh_token`, and `expires_at` (epoch
**milliseconds**). `expiresAtFromJWT(_:fallback:)` extracts `exp` from a JWT.

### `AuthCallbackResult` / `AuthLoginOptions`

```swift
public struct AuthCallbackResult: Sendable, Equatable {
  public let accessToken, refreshToken, applicationId, contextId, contextIdentity, nodeUrl: String
}

public struct AuthLoginOptions: Sendable {
  public init(callbackUrl: String, mode: String, packageName: String? = nil,
              permissions: [String]? = nil, registryUrl: String? = nil,
              packageVersion: String? = nil)
}
```

## Token stores

```swift
public protocol TokenStore: Sendable {
  func getTokens() -> TokenData?
  func setTokens(_ data: TokenData)
  func clear()
}
```

Built-in implementations:

```swift
// Secure, persisted — backed by the Keychain (Security framework)
public final class KeychainTokenStore: TokenStore {
  public init(service: String = "network.calimero.merokit",
              account: String = "mero-tokens",
              accessGroup: String? = nil,                        // shared Keychain group
              accessible: CFString = kSecAttrAccessibleAfterFirstUnlock)
}

// Ephemeral (the default when config.tokenStore is nil)
public final class MemoryTokenStore: TokenStore { public init() }
```
