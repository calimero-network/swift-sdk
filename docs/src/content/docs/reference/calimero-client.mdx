`CalimeroClient(CalimeroClientOptions(baseUrl:nodes:policy:session:retry:))`,
or `CalimeroClient.connect(CalimeroConnectOptions(cluster:policy:zone:))` to
read a Calimero Cloud cluster's nodes from the node directory. An actor.
Method names follow mero-js's `CalimeroClient`.

Methods marked with a passkey (`passkey:`) are step-ups: the node answers
`412 CONFIRM_REQUIRED` and the client answers with that passkey's assertion.
