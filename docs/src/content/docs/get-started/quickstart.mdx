## Add the package

```swift
.package(url: "https://github.com/calimero-network/swift-sdk", branch: "master")
```

Products: `MeroKit` (the client), `MeroKitUI` (SwiftUI session and app layer),
`MeroKitTestSupport` (fakes for your tests).

## A development cluster

```sh
# in calimero-network/core (merod is Linux only; on macOS run it in Docker)
cargo run -p merod -- local     # 3 nodes on 127.0.0.1:2501-2503, mock attestation
```

```swift
import MeroKit

let client = CalimeroClient(CalimeroClientOptions(
    baseUrl: "http://127.0.0.1:2501", nodes: ["http://127.0.0.1:2502", "http://127.0.0.1:2503"],
    policy: .development))                 // trusts mock attestation: development only

try await client.signUp(SoftPasskey(), name: "ada")   // a software passkey for rp `localhost`
let bundle = try await client.uploadBundle(wasm)      // dev clusters only
let app = try await client.createApp("kv", bundle: .bundle(bundle), initArgs: [:])
_ = try await client.call(app, "set", ["key": "a", "value": "1"])
let value = try await client.view(app, "get", ["key": "a"]).result
for try await event in client.events(app) { print(event.kind, event.data) }
```

## A real cluster

```swift
let client = CalimeroClient(CalimeroClientOptions(baseUrl: nodeURL, policy: .production))
try await client.signIn(PlatformPasskey())   // MeroKitUI: the device's passkey
let app = try await client.createApp("chat", bundle: .package("com.calimero.chat"), org: orgId)
```

`.production` trusts real TDX quotes only, from a signed mero-tee release at
or above `2.3.109` with the `locked-read-only` profile
([TEE trust](/guides/tee-trust/)). The device's passkey needs the cluster's
relying party in your app's Associated Domains (`webcredentials:<rp-id>`).

## In SwiftUI

```swift
@StateObject var session = MeroAppSession(
    packageName: "com.calimero.chat", callback: .scheme("myapp", path: "consent"),
    config: MeroProviderConfig(nodeURL: "https://node.example"))

.task { await session.restore() }
.onOpenURL { url in Task { await session.handle(url) } }
```

See [the app layer](/guides/app-session/).
